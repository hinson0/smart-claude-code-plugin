# show —— 自包含 HTML 审阅页

## 为什么需要它

没人会读完 300 行的 Markdown 长墙——注意力在 100 行左右就耗尽了。本 skill 把交付物渲染成一个带布局、色彩、导航和折叠的单页 HTML，让人真正读得下去、做得了决策。

一条原则统摄一切：**Markdown/对话是 Source，HTML 是 View。** 内容变化时从源头生成新的不可变页面快照；绝不通过编辑或覆盖旧快照来改变含义，页面也永远不替代原始文件、spec 或代码。

## 输入模式

**对话模式（无参数，默认）。** 提取当前会话的主交付物——用户一直在打磨的方案、分析、评审或报告。取*最终状态*而非过程：保留决策及其理由、数据、表格、代码；丢弃死胡同、工具噪音和寒暄。有多个候选时，选用户最近在处理的那个，或用尾随参数词语做主题过滤。

**文件模式（`<path>.md`）。** 读取整个文件并做视觉化重组。严格保义——可以重组、分组、折叠，但绝不发明或丢弃实质内容。

## 第 1 步——选版式配方

阅读 `references/layouts.md`，按内容选配方：

- `plan-review` —— 实现方案、提案、待拍板（go/no-go）的设计
- `explainer` —— 讲清一个系统/模块/流程如何运作；架构与调用链
- `report` —— 其余一切：研究、分析、长文档（安全兜底）

配方决定 section 顺序和使用哪些模板组件。不要自由发挥页面结构；跨次运行的一致性正是配方存在的意义。

## 第 2 步——用模板构建页面

阅读 `assets/template.html`。它是完整骨架：CSS 变量、自动明暗主题、粘性目录侧栏，以及成套组件样式（指标块、徽章、callout、details、表格、代码、双栏面板、方案对比卡、清单）。只填以下占位符，其余一律不动：

| 占位符 | 取值 |
|---|---|
| `{{LANG}}` | `zh-CN`、`en` 等——与页面内容语言一致 |
| `{{TITLE}}` / `{{TITLE_SHORT}}` | 页面标题 / 目录顶部的短标题 |
| `{{SUBTITLE}}` | 一句话：这页是什么、支撑什么决策 |
| `{{TOC}}` | `<a href="#sec-N">…</a>` 列表；子项加 `l2` 类 |
| `{{CONTENT}}` | 正文，仅用模板组件类构建 |
| `{{GENERATED_AT}}` | `date '+%F %R'` |
| `{{COMMIT}}` | `git rev-parse --short HEAD`，非仓库时用 `n/a` |
| `{{SOURCE}}` | `conversation` 或源文件路径 |

只生成*内容* HTML——绝不重写或重排骨架 CSS。模板是保证每页视觉一致的根基，也把 token 花在内容而不是外壳上。

## 铁律

- **单文件自包含。** 无 CDN、无外部样式/字体/图片、无任何网络请求。图用内联 SVG。
- **零 JavaScript。** 折叠用 `<details>`、导航用锚点、对比用并排面板。确需 tab 切换时用 `references/layouts.md` 里的纯 CSS 方案——依然无脚本。
- **出处页脚强制**（模板的 `footer.meta` 块）：生成时间、commit SHA、来源。出处不明的审阅页无法作为决策依据。
- **不落密钥。** 源内容里出现 token、密钥、凭证、内网 URL 时一律脱敏。
- **派生、不可变视图。** 绝不修改或覆盖已有页面——改为从源头生成带时间戳的新快照。

## 第 3 步——落盘、打开、汇报

1. 确保 `.smart/` 已被 git 忽略（与其他 smart 草稿文件同一约定；缺失时补进 `.gitignore`）。
2. 用 `date '+%F-%H%M%S'` 取得本次运行唯一时间戳，再选择 `.smart/pages/<YYYY-MM-DD>-<HHMMSS>-<主题-slug>.html`（kebab-case slug）。写入前必须先确定最终未占用路径：若该路径已存在，依次追加 `-2`、`-3`，直到找到未占用路径。绝不把已有页面路径交给写入或编辑操作；每次调用都必须保留此前所有页面，把它们作为不可变审阅资产。
3. 打开：macOS 用 `open <file>`，Linux 用 `xdg-open <file>`。都没有就只打印路径。
4. 控制台汇报，最多三行：文件绝对路径、所用配方、section 列表。

## 语言

页面内容语言跟随对话（中文对话 → 中文页面）。本 skill 文件与模板保持英文。
