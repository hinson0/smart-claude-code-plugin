# Fuzz Ask

## 调用边界

- 仅在用户显式调用 Codex 的 `$fuzz:ask` 或 Claude Code 的 `/fuzz:ask` 时启动。
- 其他工作流不得自动调用本 Skill。
- 不从“简明扼要”“只告诉我怎么做”等自然语言自动推断调用。

## 响应模式

- 直接说明可能原因、判断结论或下一步动作。
- 在有帮助时提供准确命令、代码片段、文件路径或检查清单。
- 只在会影响方案时说明假设。
- 只提醒影响正确性、数据丢失、安全性或明显返工的风险。

## 执行边界

- 不修改文件、不创建交付物、不运行 shell 命令、不打开浏览器、不调用外部服务、不启动子代理。
- 不用长计划代替短答案，不执行答案中描述的实现动作。
- 只有用户明确退出本模式或明确改为执行，才允许进行实现动作。
